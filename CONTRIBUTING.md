# Contributing to AIEBOK

Thank you for improving an open AI engineering reference.

1. Open an issue describing the gap, audience, and proposed page type.
2. For substantial work, copy `templates/content-spec.yml` into your working notes.
3. Create a focused branch and edit Markdown under `docs/`.
4. Run code samples and `python scripts/validate_content.py`.
5. Run `mkdocs build --strict` and inspect the local site at mobile and desktop widths.
6. Submit a pull request using the included template.

Contributions must respect source licenses, avoid secrets and personal data, and clearly label time-sensitive or vendor-specific claims. By contributing content, you agree it may be distributed under CC BY 4.0; code contributions are MIT licensed.
