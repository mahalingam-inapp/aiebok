# Off Policy Evaluation

**Purpose:** Reference card for **off policy evaluation** used across AIEBOK books and knowledge areas.

## Core explanation

Off-policy evaluation estimates the performance of a target policy from data generated by a different policy. Inverse propensity scoring reweights rewards using the ratio of target to logging probabilities. Small logging probabilities can make an estimate unstable.

## Example

A deterministic target selects an action whose logging probability was one quarter, so matching logged rows have weight four.

## When to use

Use to assess a target decision policy from data collected by another policy.

## When not to use

Withhold the estimate when the target selects actions outside the logging policy's support.

## Engineering checklist

- Inspect overlap and effective sample size before comparing values.

## Evidence of understanding

Report overlap, effective sample size and sensitivity. Withhold the estimate where the target makes unsupported choices.

## Common failure modes

- A handful of high-weight rows dominate the estimate.

## Trade-offs

No mechanism is universal. Compare off policy evaluation against a simpler baseline on normal, boundary, and adversarial cases before adding operational complexity.
