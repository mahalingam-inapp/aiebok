# AWS Implementation Guide

Map enduring capabilities to AWS services; keep this page dated and verify details before use.

- Models and agents: Amazon Bedrock
- ML training/lifecycle: Amazon SageMaker
- Retrieval: Bedrock Knowledge Bases, Amazon OpenSearch Service, Amazon Kendra
- Compute: Lambda, ECS, EKS
- Orchestration/events: Step Functions, EventBridge, SQS
- Storage/data: S3, Aurora, DynamoDB
- Identity/security: IAM, KMS, Secrets Manager, VPC, CloudTrail
- Operations: CloudWatch, X-Ray, AWS Config
