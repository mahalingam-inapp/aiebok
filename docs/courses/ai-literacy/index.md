# AI Literacy

No code · 2 sections · 4 lectures · About 2 hours, plus the project

Recognize where AI can help, where it can fail, and how to verify an output before using it.

[Start the first lecture](01-what-ai-can-do.md){ .md-button .md-button--primary .study-start data-course="ai-literacy" }

## Practice case · A message from the school office

Amal helps at a school office. A water outage closes a building with little notice. Parents need a short message explaining what has changed. The head teacher has confirmed today's closure and promised a further update, so Amal needs to decide what an AI writing tool can safely help with and what must still come from the school.

This fictional case continues through the lectures.

For a documented comparison, read [A chatbot answer that changed a travel decision](../../casebook/bereavement-fares.md).

## Course project

Make a one-page AI-use checklist for a task you encounter at work or at home.

**How to check your project**

Include the task, a simpler alternative, one fact to verify, and a reason to stop or ask a person.
