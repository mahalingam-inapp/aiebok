# AI Product Decisions

No code · 2 sections · 4 lectures · About 2 hours, plus the project

Turn an AI proposal into a measurable decision about a bounded pilot.

[Start the first lecture](01-frame-the-decision-before-selecting-a-model.md){ .md-button .md-button--primary .study-start data-course="ai-product-decisions" }

## Practice case · The clinic’s front desk is drowning in repeats

Kavita manages a clinic front desk. The team spends part of each shift answering questions about location, hours, and appointment preparation. A sponsor suggests an assistant for every inquiry. Kavita needs a narrower pilot that relieves staff without steering people toward the wrong appointment process.

This fictional case continues through the lectures.

For a documented comparison, read [What changed for customer support workers](../../casebook/support-assistants.md).

## Course project

Write a proposal for a two-week pilot of an AI feature or workflow.

**How to check your project**

State the problem and baseline, compare alternatives, define a success metric and guardrail, and name the reviewer.
