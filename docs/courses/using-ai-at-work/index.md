# Using AI at Work

No code · 2 sections · 4 lectures · About 2 hours, plus the project

Write clear requests, review generated work, and design a simple human handoff.

[Start the first lecture](01-turn-a-request-into-a-clear-brief.md){ .md-button .md-button--primary }

## Entry prerequisites

AI Literacy or equivalent. All activities can be done on paper or in a document.

## Course outline

### Request and review a draft

- [01 · Turn a request into a clear brief](01-turn-a-request-into-a-clear-brief.md) — Write a brief with context, constraints, and a checkable output.
- [02 · Review output against the source](02-review-output-against-the-source.md) — Use a short checklist to catch factual and format errors.

### Build a repeatable workflow

- [03 · Design a human handoff](03-design-a-human-handoff.md) — Write a fallback for incomplete or conflicting information.
- [04 · Measure whether the workflow helped](04-measure-whether-the-workflow-helped.md) — Compare the new workflow with the current workflow using a fair baseline.

## Course project

Improve a low-risk draft and retain a short record of the brief, checks, and edits.

**How to check your project**

Your final draft meets the brief, uses verified facts, and identifies who owns approval.
