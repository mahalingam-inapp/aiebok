# Specify the workload and critical failures

[Model Selection Decisions for Leaders](index.md) · Frame the decision · Lecture 1 of 4 · 20–30 min · No code

## What you will learn

Turn a model shortlist into an evaluation brief tied to representative work.

## How it works

Define the users, tasks, wrong outcomes, and acceptable fallback. Use equivalent inputs and evidence for each candidate. Reserve a critical slice for outcomes that should block a pilot.

## Worked example

An employee policy assistant can draft answers, abstain on unknown questions, and preserve access boundaries. Restricted-policy behavior is critical.

## Try it yourself
