# KA 15 — AI Operations

## Content plan

Prompt, model, dataset, and evaluation versioning; experiment tracking; traces; logs; metrics; token/cost attribution; quality monitoring; drift; feedback; canaries; A/B tests; fallbacks; rollbacks; incident response; capacity; SLOs; FinOps; and continuous evaluation.

## Code practice

Instrument an AI request across retrieval, model, tools, validation, and response. Inject timeout, malformed output, irrelevant retrieval, and provider failure; verify recovery and alerts.

## Operating model

Every release should connect a versioned change to evaluation evidence, deployment state, observed outcomes, and a rollback path.
