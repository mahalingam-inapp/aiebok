# KA 17 — Multimodal AI

## Content plan

Vision encoders, OCR, document layout, images, speech recognition, speech synthesis, audio, video, diffusion, multimodal embeddings, fusion, grounding, temporal understanding, accessibility, provenance, watermarking, and robotics interfaces.

## Code practice

Build a document-understanding pipeline that extracts text, tables, and images, preserves page references, and evaluates field-level accuracy.

## Architecture question

Decide when to preprocess into text, when to use native multimodal input, and how to retain provenance across transformations.
