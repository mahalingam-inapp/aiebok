# KA 13 — Model Training

## Content plan

Data curation, deduplication, contamination, tokenization choices, pretraining, continued pretraining, supervised fine-tuning, parameter-efficient tuning, LoRA, QLoRA, preference data, RLHF, DPO, distillation, synthetic data, model merging, checkpoints, reproducibility, and post-training evaluation.

## Code practice

Fine-tune a small open model on a narrow behavior task. Compare against prompting and RAG baselines, and evaluate before/after on held-out and safety cases.

## Decision question

Is the problem missing knowledge, undesired behavior, insufficient capability, or poor system design? Each implies a different intervention.
