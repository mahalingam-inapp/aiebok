# Learning Paths

## AI engineer — 24 weeks

Foundations → language → transformers → models → prompt/context → knowledge → tools → agents → evaluation → operations. Complete Labs 1–5 and the enterprise RAG architecture studio.

## Software architect — 12 weeks

Survey foundations and models; focus on context, knowledge systems, tools, agents, AI software engineering, safety, infrastructure, operations, and enterprise architecture. Produce five ADRs and two threat models.

## Product/technical leader — 8 weeks

Models → prompt/context → evaluation/safety → enterprise architecture → product engineering. Focus on capability boundaries, uncertainty, human oversight, adoption, ROI, and build-versus-buy.

## ML engineer — 16 weeks

Machine learning → representation → transformers → models → training → infrastructure → evaluation → operations. Add profiling and before/after evaluation to every lab.

## Coding-agent specialist — 10 weeks

Prompt/context → reasoning → tools → agents → AI software engineering → coding ecosystem → evaluation/safety. Build a spec-to-code workflow with explicit approval gates.
