# LLM Evaluation & Model Selection Engineer

Specialist · evaluation · 4 courses

Engineers who own model comparisons, grading protocols, or release evidence.

## Entry prerequisites

Basic statistics, Python, and experience building or evaluating a model-backed application.

## Study pace

Plan for 10–12 hours per technical core course, 3–4 hours per practicum, and about two hours per no-code course, plus project work. Use the core course checkpoints to prepare for the applied workbooks. Budget additional time for the capstone.

## Completion evidence

Publish a paired comparison with agreed rating criteria and a defensible model or release decision. Follow the [capstone brief and rubric](llm-evaluation-capstone.md).
