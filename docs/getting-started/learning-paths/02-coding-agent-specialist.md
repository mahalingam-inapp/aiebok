# Coding-Agent Specialist

Intermediate · 6 courses

Software engineers building supervised coding workflows.

## Entry prerequisites

Python, testing, Git, and familiarity with model inference and retrieval, or finish the Software Engineer path.

## Course sequence

1. [Prompt and Context Engineering](../../books/05-prompt-and-context-engineering/index.md)
2. [Reasoning and Tool Use](../../books/07-reasoning-and-tool-use/index.md)
3. [Agent Systems](../../books/08-agent-systems/index.md)
4. [AI Software and Product Engineering](../../books/09-ai-software-and-product-engineering/index.md)
5. [Evaluation, Safety, and Governance](../../books/10-evaluation-safety-and-governance/index.md)
6. [Supervised Coding-Agent Harnesses](../../courses/supervised-coding-harness/index.md)

## Study pace

Plan for 10–12 hours per technical core course, 3–4 hours per practicum, and about two hours per no-code course, plus project work. Use the core course checkpoints to prepare for the applied workbooks.

## Completion evidence

Demonstrate a supervised change with a typed proposal, a failing and passing regression case, an approval record, and a replay check.
