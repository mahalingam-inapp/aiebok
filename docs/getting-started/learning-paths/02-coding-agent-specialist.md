# Coding-agent specialist

**Duration:** ~10 weeks · **Steps:** 36 · **Complexity rank:** 2 of 5

Software engineers building spec-to-code workflows, tool-using agents, and guarded automation with explicit approval gates.

**Outcome:** Ship a bounded coding-agent workflow with structured outputs, tool boundaries, regression evals, and a documented approval policy.
