# LLM Adaptation & Inference Engineer

Advanced specialist · models · 5 courses

ML engineers selecting and adapting models and measuring serving trade-offs.

## Entry prerequisites

Python, basic linear algebra, and held-out evaluation. Start with Machine Learning Systems if these are unfamiliar.

## Course sequence

1. [Machine Learning Systems](../../books/02-machine-learning-systems/index.md)
2. [Transformers and Foundation Models](../../books/04-transformers-and-foundation-models/index.md)
3. [Training, Serving, and AI Operations](../../books/11-training-serving-and-ai-operations/index.md)
4. [Model Selection and Adaptation Lab](../../courses/model-selection-and-adaptation/index.md)
5. [LLM Adaptation and Inference Lab](../../courses/llm-adaptation-inference/index.md)

## Study pace

Plan for 10–12 hours per technical core course, 3–4 hours per practicum, and about two hours per no-code course, plus project work. Use the core course checkpoints to prepare for the applied workbooks. Budget additional time for the capstone.

## Completion evidence

Compare a frozen and adapted model against a retrieval baseline on the same held-out workload. Follow the [capstone brief and rubric](llm-adaptation-capstone.md).
