# Forward-Deployed AI Engineer

Specialist · customer delivery · 4 courses

Engineers delivering a pilot inside a customer’s existing workflow.

## Entry prerequisites

Complete Software Engineer Building with AI or bring equivalent Python, integration, and evaluation experience.

## Study pace

Plan for 10–12 hours per technical core course, 3–4 hours per practicum, and about two hours per no-code course, plus project work. Use the core course checkpoints to prepare for the applied workbooks. Budget additional time for the capstone.

## Completion evidence

Deliver an accepted synthetic customer pilot with a working intake integration and an operator handoff. Follow the [capstone brief and rubric](forward-deployed-capstone.md).
