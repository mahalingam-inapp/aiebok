# Model Selection for Leaders Capstone

Your operations team must choose a model for a bounded policy-assistant pilot. Use the shared scorecard in [Model Selection Decisions for Leaders](../../courses/model-selection-for-leaders/index.md). The purchasing decision must account for reviewer time as well as evaluation spend.

## Milestones

1. Describe the audience, expected outcomes, and the critical failures that would stop the pilot.
2. Apply the critical and latency gates, then estimate cost per correct task. State what evidence you would gather to price review work.
3. Write a one-page recommendation with an approval owner, a pause condition, and evidence that might reverse the decision.

## Rubric

| Evidence | Complete when |
|---|---|
| Fair comparison | All candidates face the same workload and predeclared gates. |
| Economics | The decision includes observed cost per correct result and names the missing review-cost evidence. |
| Launch control | The proposed rollout is bounded and has an owner, stop condition, and follow-up test. |
