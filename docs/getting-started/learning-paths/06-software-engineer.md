# Software Engineer Building with AI

Technical foundations · 9 courses

Developers adding model-backed features to existing applications.

## Entry prerequisites

Comfort with Python and automated tests. Start with Courses 01 and 02 if ML or basic algebra is unfamiliar.

## Study pace

Plan for 10–12 hours per technical core course, 3–4 hours per practicum, and about two hours per no-code course, plus project work. Use the core course checkpoints to prepare for the applied workbooks.

## Completion evidence

Demonstrate a source-grounded feature with a validated response, fallback, access boundaries, and a baseline comparison on frozen cases.
