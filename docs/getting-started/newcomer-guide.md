# Newcomer Guide

Start with a [learning path](learning-paths/index.md) to follow an ordered set of courses, or choose one course from the [catalog](../courses/index.md).

## Choose a starting point

| Your goal | Start here |
|---|---|
| Understand AI and use it safely in everyday work | [AI for Everyone](learning-paths/00-ai-for-everyone.md) |
| Evaluate AI proposals, lead pilots, or make release decisions | [AI for Managers and Product Leaders](learning-paths/01-product-technical-leader.md) |
| Add AI features to a software application | [Software Engineer Building with AI](learning-paths/06-software-engineer.md) |
| Study an engineering specialty or work through the full curriculum | [All learning paths](learning-paths/index.md) |
| Look up terminology or compare designs | [Knowledge areas](../knowledge-areas/index.md) and [concepts](../concepts/index.md) |

## Work through a course

1. Read the course prerequisites and open its first lecture. Each lecture explains its topic, walks through an example, and gives you practice and a knowledge check.
2. Finish each section's lectures before moving to the next section. No-code courses use scenarios and answer examples. Technical courses include a downloadable [Jupyter workbook](../labs/notebooks/index.md) with lecture demonstrations and a checked workshop.
3. Finish the course project and compare what you made with the stated completion evidence. Return to your learning path to find the next course.

You can complete no-code paths entirely on the site. For technical practice, see [notebook setup](../labs/notebooks/index.md). The [starter notebooks](../labs/start-here.md) provide a short introduction to retrieval, agents, and evaluation if you want to try those topics first.
