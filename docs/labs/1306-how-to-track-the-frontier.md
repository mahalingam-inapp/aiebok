# Lab 13.6 — How to Track the Frontier

## Objective

Write a one-page frontier assessment with confidence levels.

## Prerequisites

Book [Multimodal and Frontier Systems](../books/13-multimodal-and-frontier-systems/index.md), chapter 6.

## Run

```bash
python labs/1306-how-to-track-the-frontier/main.py
python -m pytest labs/1306-how-to-track-the-frontier/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
