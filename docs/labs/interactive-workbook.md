# HarborLink interactive workbook

HarborLink is a fictional transit help desk. Ask about an accessible station entrance, look up a fare refund deadline, or send an unresolved request to a staff reviewer. The answer uses policy evidence for the selected date and simulated audience.

[Open HarborLink](../assets/workbooks/harborlink.html){ .md-button .md-button--primary }
[Download the HTML](../assets/workbooks/harborlink.html){ .md-button download }

Open the downloaded file in a browser with JavaScript enabled. The code, data, curriculum map, and styles are bundled in that file. Each notebook section controls whether its module runs. Close ranked retrieval to use the built-in policy lookup. Close the workflow module to use a manual staff handoff. With every module closed, the service still checks policy dates, audience, evidence, and the context budget.

Try the current and previous fare refund policies, or open ranked retrieval to compare methods on the elevator question. Open evaluation and select **Run open cells** to display fixed-case results for the current configuration. Use **Curriculum map** to find modules connected to a lecture or knowledge area.

The workbook uses local example policies, prewritten transcripts and image text, and a simulated operations environment. It includes runnable retrieval, grounding, evaluation, routing, and review controls, with short notes for topics that need external models or infrastructure. Continue with the [Jupyter notebooks](notebooks/index.md) for Python exercises and worked explanations.
