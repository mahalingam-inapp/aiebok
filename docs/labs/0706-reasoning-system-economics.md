# Lab 7.6 — Reasoning-System Economics

## Objective

Plot quality and cost for single-pass, best-of-N, and verifier loops.

## Prerequisites

Book [Reasoning and Tool Use](../books/07-reasoning-and-tool-use/index.md), chapter 6.

## Run

```bash
python labs/0706-reasoning-system-economics/main.py
python -m pytest labs/0706-reasoning-system-economics/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
