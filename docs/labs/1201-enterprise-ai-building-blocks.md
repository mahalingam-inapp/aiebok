# Lab 12.1 — Enterprise AI Building Blocks

## Objective

Draw a logical platform architecture before naming products.

## Prerequisites

Book [Cloud and Enterprise AI Architecture](../books/12-cloud-and-enterprise-ai-architecture/index.md), chapter 1.

## Run

```bash
python labs/1201-enterprise-ai-building-blocks/main.py
python -m pytest labs/1201-enterprise-ai-building-blocks/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
