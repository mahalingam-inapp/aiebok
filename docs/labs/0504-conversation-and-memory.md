# Lab 5.4 — Conversation and Memory

## Objective

Implement a conversation summarizer and memory scoring policy.

## Prerequisites

Book [Prompt and Context Engineering](../books/05-prompt-and-context-engineering/index.md), chapter 4.

## Run

```bash
python labs/0504-conversation-and-memory/main.py
python -m pytest labs/0504-conversation-and-memory/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
