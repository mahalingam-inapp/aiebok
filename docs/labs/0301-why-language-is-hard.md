# Lab 3.1 — Why Language Is Hard

## Objective

Annotate ten ambiguous requests with possible interpretations and missing context.

## Prerequisites

Book [Language and Representation](../books/03-language-and-representation/index.md), chapter 1.

## Run

```bash
python labs/0301-why-language-is-hard/main.py
python -m pytest labs/0301-why-language-is-hard/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
