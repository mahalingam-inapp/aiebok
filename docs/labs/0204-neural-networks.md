# Lab 2.4 — Neural Networks

## Objective

Train a small network and inspect gradients and learning curves.

## Prerequisites

Book [Machine Learning Systems](../books/02-machine-learning-systems/index.md), chapter 4.

## Run

```bash
python labs/0204-neural-networks/main.py
python -m pytest labs/0204-neural-networks/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
