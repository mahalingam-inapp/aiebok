# Lab 13.4 — Computer Use and Embodied Action

## Objective

Design a safe browser task with confirmation and recovery.

## Prerequisites

Book [Multimodal and Frontier Systems](../books/13-multimodal-and-frontier-systems/index.md), chapter 4.

## Run

```bash
python labs/1304-computer-use-and-embodied-action/main.py
python -m pytest labs/1304-computer-use-and-embodied-action/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
