# Lab 1.4 — The Mathematics Engineers Need

## Objective

Compute dot products, cosine similarity, softmax, and one gradient update by hand.

## Prerequisites

Book [Foundations of Intelligence](../books/01-foundations-of-intelligence/index.md), chapter 4.

## Run

```bash
python labs/0104-the-mathematics-engineers-need/main.py
python -m pytest labs/0104-the-mathematics-engineers-need/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
