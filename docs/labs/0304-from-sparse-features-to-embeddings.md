# Lab 3.4 — From Sparse Features to Embeddings

## Objective

Implement TF–IDF and compare it with the included vector lab.

## Prerequisites

Book [Language and Representation](../books/03-language-and-representation/index.md), chapter 4.

## Run

```bash
python labs/0304-from-sparse-features-to-embeddings/main.py
python -m pytest labs/0304-from-sparse-features-to-embeddings/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
