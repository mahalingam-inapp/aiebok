# Lab 9.5 — Human-Centered AI UX

## Objective

Prototype a high-risk action flow with preview and approval.

## Prerequisites

Book [AI Software and Product Engineering](../books/09-ai-software-and-product-engineering/index.md), chapter 5.

## Run

```bash
python labs/0905-human-centered-ai-ux/main.py
python -m pytest labs/0905-human-centered-ai-ux/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
