# Lab 1.5 — Learning and Generalization

## Objective

Fit increasingly flexible models to a small noisy dataset and plot errors.

## Prerequisites

Book [Foundations of Intelligence](../books/01-foundations-of-intelligence/index.md), chapter 5.

## Run

```bash
python labs/0105-learning-and-generalization/main.py
python -m pytest labs/0105-learning-and-generalization/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
