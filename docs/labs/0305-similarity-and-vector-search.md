# Lab 3.5 — Similarity and Vector Search

## Objective

Run the cosine and semantic-search labs, then add hybrid scoring.

## Prerequisites

Book [Language and Representation](../books/03-language-and-representation/index.md), chapter 5.

## Run

```bash
python labs/0305-similarity-and-vector-search/main.py
python -m pytest labs/0305-similarity-and-vector-search/test_lab.py -q
```

## Exercises

1. Predict output, run `main.py`, compare.
2. Modify one mechanism-specific line and re-run tests.
3. Document normal, boundary, and adversarial cases.
4. Compare against a simpler baseline approach.

## Exit criteria

`main.py` runs cleanly and `test_lab.py` passes; you can explain *why* behavior changed, not only that it ran.
