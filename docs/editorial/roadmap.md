# Expansion Roadmap

## Release 0.1 — Foundation (included)

Navigation, all 20 knowledge-area plans, sample concepts/patterns/architecture, cloud maps, five labs, editorial templates, validation, deployment, and licensing.

## Release 0.2 — First complete reading path

- Expand Foundations, Representation, Transformers, Context, Knowledge, Agents, and Evaluation to 6–10 lessons each.
- Add 30 concept cards and 10 patterns.
- Add diagrams and mastery questions.
- Add citations to primary sources and official cloud documentation.

## Release 0.3 — Practice depth

- Convert five starter labs into guided notebooks plus tests.
- Add architecture studios for coding agents and document processing.
- Add provider-neutral model and retrieval evaluation harnesses.
- Add GitHub Codespaces or Dev Container support only if contributor demand justifies it.

## Release 0.4 — Comprehensive reference

- Expand every knowledge area.
- Add an alphabetical glossary and question index.
- Generate prerequisite and “unlocks” views from metadata.
- Add print/PDF styling only after web/mobile quality stabilizes.

## Maintenance cadence

Run a quarterly vendor/frontier review, semiannual evolving-content review, annual broken-link and curriculum-gap audit, and biennial enduring-content review.

## Deliberately out of scope

Accounts, progress tracking, quizzes stored on a server, payments, cohorts, certificates, and other LMS features.
